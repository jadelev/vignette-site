# Vignette — vignette.events

The website for Vignette, an experiential design studio: rituals, revelry & reunion.

## What's here
- `index.html` — the homepage
- `enquire.html` — the enquiry page and form (sends to hello@jadelevinson.com via FormSubmit)
- `assets/styles.css` — all styling (colors and type are set at the top)
- `assets/site.js` — the phone menu and the form
- `assets/img/` — photos, already graded and sized
- `assets/logo/` — the seal, wordmark, favicon and social image

## Quick edits
- **Text:** open `index.html`, click the pencil icon, change the words, commit. The site updates within a minute or two.
- **Photos:** upload a new file into `assets/img/` with the same name as the one you're replacing.
- **Hidden sections:** Festival of Woman, Unison and the quote section carry a `hidden` attribute in `index.html`. Delete the word `hidden` to show one.
